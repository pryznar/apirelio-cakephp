# Changelog

## 1.0.1 - 2026-09-20

- Refresh the tested framework and development dependency baseline.
- Publish the PHP SDK maintenance release.

## 1.0.0 - 2026-08-28

- Publish the first stable CakePHP SDK on PHP Core 1.x.
- Test CakePHP 5 through PHP 8.5 and PHPUnit 13.
- Report the published SDK version in telemetry.

## 0.1.0 - 2026-08-28

- Add CakePHP 4.5 and 5.x PSR-15 request middleware.
- Add matched-route, route-name, exception and safe request-context capture.
- Add customer and consuming-application resolvers.
- Add synchronous and file-buffered delivery backed by Apirelio PHP Core.
