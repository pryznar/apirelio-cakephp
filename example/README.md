# CakePHP example

Copy the middleware registration into your CakePHP application's `src/Application.php`, then add the controller context example where a stable domain error code is known.

```bash
composer require apirelio/cakephp:^0.1
export APIRELIO_API_KEY=apr_live_your_key
```

The SDK sends normalized route templates and operational outcomes. It never sends controller request data or response bodies.
